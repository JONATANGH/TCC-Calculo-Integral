# Resolutor de integrales definidas

Trabajo de Cálculo Integral, Ingeniería de Software, Universidad de Cartagena.

Aplicación en Python con interfaz Tkinter que resuelve las 10 integrales definidas de la guía y también una integral escrita por el usuario. Muestra la notación matemática, la técnica, el procedimiento paso a paso, el resultado exacto, la aproximación decimal y la gráfica del área. Verifica cada resultado con SciPy.

Jonatan Jose Gomez Herrera, Luis Santiago Morelo Espitia, Ivan Andrés Cogollo López, Dhylan Jose Petro Ramos y Carlos Arturo Flórez Dugarte.

## Cómo usarlo
Opción 1, sin instalar nada: descargar ResolutorIntegrales.exe desde la sección Releases y abrirlo en Windows.

Opción 2, desde el código: instalar Python 3.10 o superior, abrir una terminal en la carpeta y ejecutar:

pip install -r requirements.txt
python app.py

## Archivos
integrales.py: las 10 integrales, sus técnicas y la resolución con SymPy y SciPy.
app.py: la interfaz y la gráfica.
build_exe.bat: genera el ejecutable con PyInstaller.
capturas: imágenes del programa funcionando.
TCC_Resolucion_manual.docx: resolución a mano de las integrales 5 y 7.
